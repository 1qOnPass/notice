# 외부망 인사시스템 이용 일시 중단 안내

인터넷이 연결되지 않은 환경에서도 단독으로 열 수 있는 반응형 보안 공지 페이지입니다.

## 파일 구성

- `index.html` — 공지 페이지
- `styles.css` — 반응형 스타일
- `script.js` — jQuery 기반 초기 화면 전환과 오프라인 캐시 등록
- `jquery-3.7.1.min.js` — 오프라인 실행을 위한 로컬 jQuery
- `fonts/Hana2-Bold.woff2` — 화면 전체에 적용되는 하나 전용 웹폰트
- `images/onepass-app.png` — 헤더에 표시되는 1Q ON PASS 앱 이미지
- `images/hanati-logo.png` — 공식 홈페이지에서 가져온 푸터용 하나금융TI 로고
- `sw.js` — 첫 방문 이후 오프라인에서도 페이지가 열리도록 하는 캐시
- `.nojekyll` — GitHub Pages 정적 배포 설정

## 사용 방법

이 폴더 안의 파일을 모두 GitHub 저장소 최상위에 업로드하고, 저장소의 **Settings → Pages**에서 배포할 브랜치를 선택합니다.

인터넷 없이 확인하려면 폴더를 통째로 전달한 뒤 `index.html`을 열면 됩니다. 외부 폰트, 이미지, 스크립트를 요청하지 않습니다. GitHub Pages에서는 온라인으로 한 번 방문한 뒤부터 오프라인 캐시가 적용됩니다.

단색 브랜드 컬러를 사용한 한 화면짜리 공지로, 별도 날짜나 시간 정보 없이 제목과 안내문만 표시합니다.
